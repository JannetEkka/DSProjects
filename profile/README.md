Hi, I'm Jannet. I build LLM agents, and I test them before I trust them.

I spent four years at Deloitte leading QA automation for clients like AT&T and HPE. Then I finished Rank 1 in UT Austin McCombs' Post Graduate Program in AI/ML. Now I'm in Kolkata, I'm a full-time family carer, and I build in the hours in between.

The habit I brought from QA is to measure first. When I graded my trading bot's six AI agents on market data they hadn't seen, all six called direction at a coin flip. So I rebuilt it: written rules open every trade, and the agents became advisors that get graded on every call.

### What I'm working on

**Smart Money Trading (SMT)** is an explainable AI trading agent. I've built it alone since January 2025: I direct AI coding agents and review every merge myself. It has 87,000 lines of Python and 3,100+ tests, it runs 24/7 on free tiers, and it's patent pending in India. Public layer: [smt-apac](https://github.com/JannetEkka/smt-apac).

### Things I've built, and what I measured

| Project | What it does | The number |
|---|---|---|
| [Lore](https://github.com/JannetEkka/lore) | Answers "who knows this part of the code?" from a repo's PR history, in a FalkorDB graph | A real reviewer in its top 3 on 90% of 300 FalkorDB PRs, against 88% for just picking the most frequent reviewer |
| [Chithi](https://github.com/JannetEkka/chithi) | Explains a phone photo of an Indian bill or notice in Bengali, Hindi or English | 0 of 114 dates and amounts shown wrong; 53 of 53 planted errors held back |
| [Lights Out](https://github.com/JannetEkka/lights-out) | A Hermes Agent plugin that asks a person before any billable AWS create | 0 creates without a yes, against 13 and 14 without the plugin |
| [Wiretrap](https://github.com/JannetEkka/wiretrap) | Security tests an AI agent by reading which tools it really called | Caught an agent saying it had no access right after it ran `ls -la` |
| [Countersign](https://github.com/JannetEkka/DSProjects/blob/main/projects/countersign.md) | Shows a claim from a model-written brief only after a second check confirms it | Caught 41 of 60 planted errors, and wrongly struck 19% of true sentences |
