Lore

Who knows what in a GitHub repo, with the PRs to prove it

Point Lore at any public GitHub repo

Lore reads the last 12 months of pull requests, reviews, issues and comments, works out which people know which parts of the code, and answers questions from that history. Every answer cites the PRs and issues behind it.

Reading the history…

    Areas of the code by how much changed in them, and the people who know each best. Merged PRs count most, then reviews, then comments; recent work counts more.

    Pick an open issue: Lore finds related past work and who knows that part of the code, and drafts a first reply. Nothing is posted anywhere.

    Areas with at least 3 merged PRs in the last six months that at most one active person knows well. If that person leaves, nobody else does.

    Reads public GitHub data only, from your browser. Keeps GitHub logins, never emails or names. Answers use your Anna model.
