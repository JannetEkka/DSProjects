# Hackathons, November 2026

Cash-prize hackathons and competitions that are open in November 2026, in any field, searched on **2026-11-08** (operator: "any field, cash prizes; don't worry about deadlines or overlapping build time"). Sorted by the date each one **closes**. Every closing time is converted to IST.

**Where this comes from.** I pulled every open and upcoming hackathon from Devpost's listing API (193 events: 88 open, 105 upcoming) and read the rules pages and eligibility sidebars of every Devpost event with a meaningful cash prize. Elsewhere I read the official pages where they loaded: NEAR, QIE, Code for India, Hack2skill, Agentware, Founding.dev, itch.io jam pages and the AIcrowd card. I also checked the aggregators Hackathon Radar, Web3 Voyager, Reconscribe, insiderOne, Indian AI Community and AgentDeadlines. **[HackList](https://hacklist.io/)** was added later the same day, from a post Jannet found on X: the X post itself returns 402 to automated reads, but hacklist.io embeds its whole list of 226 entries in its page data, so I read all of them. Rows from HackList alone are marked *(HackList)*. **Not readable by automated sessions:** Kaggle competition pages (title only), DoraHacks' API (a human-verification wall; its event detail pages do load), Unstop (cookie wall), Encode Club (rendered in JavaScript), and two roundup threads on X (blocked). Facts that come only from an aggregator are marked *(unverified)*. Confirm every one on the official page before entering.

**Standing rules still apply.** They are in [october-2026.md](october-2026.md): no hackathon that needs our own money (mainnet gas, funded trading accounts, paid credits); free tiers and organiser credits only; testnet or devnet wallets with faucet tokens are fine; ask Jannet for a new key for each entry; **no GCP**, so use Oracle Cloud if an entry needs a cloud; the entry's repo holds the project only; every README and pitch states the impact. Cards: [cards.md](cards.md). **Before starting any entry, check the idea against [lessons.md](lessons.md)** (what the JigJoy and Qloo winners did, and the HackerRank judges' feedback, 11-08). **None of the open events below needs a card to enter**, as far as their pages say.
