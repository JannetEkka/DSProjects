  • Graded my own multi-agent committee (six persona agents and a learned Judge) on independent market data. All six called direction at a coin flip. Rebuilt on that result: written rules with replayed records open every trade, and the agents became advisors graded on every call, earning a veto only after 30 proven warnings.
  • Every explanation passes a counterfactual test before a user sees it: flip the advisor's input and re-run the decision; if the decision doesn't change, the reason is dropped. The learning loop retunes only through a CPCV + Deflated Sharpe + PBO + FDR gate, which still holds a forecaster that scored AUC 0.723 on a BTC forward test in shadow.
  • Tested 1,800 strategy variants, 36 million simulated trades from 2020 to 2026 at six exchanges' published fees, replayed through the production code. Nothing holding a position under four hours cleared its fees. The crash-buy rule that did: 312 trades, 73% won, +4.76% average after fees, positive in every year.
  • Audited 98 AI-written merges line by line and found two failures the green test suite missed: an order-format bug that had rejected 1,137 live orders over three months, and a memory freeze that kept the daemon down 60% of the time for ten days. A fix now counts as done only when the production log shows it.
  • Runs 24/7 and places real orders on WEEX's exchange-granted simulated account (about $10K). When the GCP billing account closed, I moved the live system to a zero-cost stack in two days (Oracle Cloud free-tier VM, Cloudflare Workers, Google AI Studio's free tier) and it re-adopted its three open positions from committed state. Any substituted default logs a warning and a liveness flag, a rule that has caught four multi-week data bugs.

Wiretrap — Adversarial Security Testing for AI Agents · Gen AI Academy APAC, Cohort 3
2026
github.com/JannetEkka/wiretrap
  • A security tester that checks which tools an agent actually called. Most scanners grade the agent's reply. This one reads the tool-call log.
  • Every tool the agent declares is cloned as a dead copy with the same name and JSON Schema that records the call and returns fake data. Attacks run in separate Gemini conversations and a judge model reads the log.
  • Caught a Google codelab agent saying "I don't have access or authorization to modify configuration files" after it had already run ls -la through its shell tool. Text scanners pass that; Wiretrap flags it with the arguments.
  • A run with nothing classified reports INCONCLUSIVE, never HARDENED. Approved fixes are re-run against the attacks that broke them, and the report says when one didn't hold. 8 attack categories, 9.4K lines of TypeScript.
