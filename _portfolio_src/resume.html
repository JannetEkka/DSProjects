Wiretrap. Adversarial Security Testing for AI Agents · Gen AI Academy APAC, Cohort 3
2026
wiretrap.ai.studio·github.com/JannetEkka/wiretrap
  • Built a security tool that checks which tools an agent actually called. Most scanners read the agent's reply and grade the text. This one reads the tool-call log.
  • Every tool the agent declares gets cloned as a dead copy with the same name and JSON Schema. The copy records the call and returns fake data. Attacks run in separate Gemini conversations and a judge model reads the log.
  • Caught a Google codelab agent saying "I don't have access or authorization to modify configuration files" after it had already run ls -la through its shell tool. Text scanners pass that. Wiretrap flags it and shows the arguments.
  • A run with nothing classified reports INCONCLUSIVE, never HARDENED. Attacks against tools the agent doesn't have are dropped from the score. Approved fixes get re-run against the attacks that broke it, and the report says when one didn't hold.
  • 8 attack categories, 9.4K lines of TypeScript, React and Express on Cloud Run. Vertex AI through Application Default Credentials with a four-model fallback. No static API key anywhere in the app.
Tech: TypeScript, React, Express, Vertex AI & Gemini, Cloud Run, Firestore, Secret Manager, Google AI Studio
